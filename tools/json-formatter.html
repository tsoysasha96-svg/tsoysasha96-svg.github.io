Что делает этот инструмент

      
JSON formatter приводит «сжатый» или неаккуратно записанный JSON к читаемому виду с отступами, либо, наоборот, сжимает его в одну строку без пробелов (минификация) — так JSON обычно передают по сети. Валидатор проверяет, что структура корректна, и если нет — показывает, в какой строке и позиции парсер споткнулся.


      
Частые ошибки в JSON

      
    
        
  • Лишняя запятая перед } или ] — в JSON, в отличие от JS-объектов, висячая запятая запрещена.
    • 
        
  • Одинарные кавычки 'like this' вместо двойных "like this".
    • 
        
  • Ключи объекта без кавычек: {name: "Alex"} вместо {"name": "Alex"}.
    • 
        
  • Комментарии — JSON не поддерживает // или /* */.
    • 
        
  • Незакрытые строки или скобки.
    • 
      


      
Часто задаваемые вопросы

      
Отправляются ли мои данные на сервер?
Нет, весь разбор происходит локально в браузере через JSON.parse. Ничего не сохраняется и никуда не уходит.

      
Чем форматирование отличается от минификации?
Форматирование добавляет отступы для читаемости, минификация убирает всё лишнее, чтобы JSON занимал меньше места.
